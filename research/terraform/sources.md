# Terraform sources

Fetched 12 November 2026.

- https://github.com/hashicorp/terraform/releases/tag/v1.17.1 is Terraform 1.17.1, published 28 October 2026. The notes are bug fixes: `fmt` preserves the original file if a write fails, module policies run during a destroy plan, and stacks report every policy result for a replaced resource.
- https://docs.aws.amazon.com/service-authorization/latest/reference/reference_policies_actions-resources-contextkeys.html is the reference for actions that have no resource-level permissions and therefore require `Resource "*"`.
