# Laravel sources

Fetched 12 November 2026.

- https://laravel.com/framework/docs/13.x/releases lists Laravel 13 as PHP 8.3–8.5 and says 13.x requires PHP 8.3. It was released 17 March 2026.
- https://laravel.com/framework/docs/13.x/upgrade says Laravel 13 renamed the CSRF middleware to `PreventRequestForgery`. `ValidateCsrfToken` and `VerifyCsrfToken` remain as deprecated aliases. The class page is https://api.laravel.com/docs/13.x/Illuminate/Foundation/Http/Middleware/PreventRequestForgery.html.
- https://laravel.com/docs/master/queues#class-structure documents `SerializesModels`, which stores the model identifier.
- https://laravel.com/docs/13.x/boost is Laravel Boost, the guidelines and MCP installer.
