# React sources

Fetched 12 November 2026.

- Registry: https://registry.npmjs.org/react reports `latest` 19.3.1.
- https://react.dev/blog/2026/09/09/react-19-3 (9 September 2026) stabilizes View Transitions and Fragment refs, and documents `use(browser())` for browser-only rendering. Those are DOM APIs, not React Native APIs.
- https://react.dev/reference/react/ViewTransition and https://react.dev/reference/react/Fragment are the API pages.
- https://react.dev/reference/react-dom/browser documents `browser()`.
- https://react.dev/reference/react/forwardRef says `ref` is a prop on function components, so new components do not need `forwardRef`.
- https://react.dev/versions lists 19.3 as the current docs version.
