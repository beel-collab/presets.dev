## Install

Append the native section to the project `GEMINI.md`. Do not replace a file the team already maintains. Gemini CLI concatenates global `~/.gemini/GEMINI.md`, workspace files, and just-in-time files beside the directories it reads. Confirm the result with `/memory show`, then `/memory reload` after an edit.

`@file` imports pull another file into this context, including outside a fence. This section does not use an import.

Do not package this as a TOML command or an extension for the standards slot. Commands are a separate, user-invoked surface. Extension subagents are preview and are not part of this entry.

The audit procedure is the skill at `.gemini/skills/nextjs-tenant-cache-audit/SKILL.md`. Activation calls `activate_skill` and waits for a consent prompt. Do not skip that prompt. At the same tier, `.agents/skills` outranks `.gemini/skills`. Install this skill only under `.gemini/skills/` when a Codex skill of the same name already occupies `.agents/skills`.
